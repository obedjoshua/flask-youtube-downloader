# Lucid - Universal Media Workspace

A professional, Miter-styled media downloader and workspace web application inspired by Lucidchart's clean interface design. Built with Flask, `yt-dlp`, `spotipy`, and FFmpeg, it supports multi-platform media downloads, YouTube 8K exploring, and real-time batch music/playlist downloading with album art.

🌐 **Live Application:** [https://flask-youtube-downloader-o005.onrender.com](https://flask-youtube-downloader-o005.onrender.com)

---

## Features

* **Lucidchart-Inspired UI:** Sharp-edged (mitered) aesthetic with zero curved borders, custom dark/light mode toggling, and an Ultramarine / Off-Cream design system.
* **Music & Playlist Workspace:** Extract tracklists from Spotify or YouTube playlists, preview album art, select individual tracks, and batch download with automated real-time progress tracking.
* **Universal Media Downloader:** Paste links from TikTok, Instagram, X/Twitter, YouTube, and over 1,000+ supported sites with custom clipping and subtitle (CC) embedding.
* **YouTube 8K Explorer:** Search videos, filter by resolution (up to 8K Ultra HD) and view count, and download directly.

---

## Tech Stack

* **Backend:** Python, Flask, `yt-dlp`, `spotipy`, Gunicorn
* **Media Processing:** FFmpeg / FFprobe (Dynamic automated system path finder)
* **Frontend:** HTML5, CSS3 (Custom Grid Workspace Layout), Vanilla JavaScript
